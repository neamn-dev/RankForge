# Roadmap

- [x] **Phase 1 — Foundation:** repo, schemas, FastAPI + SQLite, health check,
      template CRUD, Template Studio v1 (header/ranking/labels/branding + preview)
- [ ] **Phase 2 — Template Studio polish:** gradients/shapes, import/export of
      template JSON, undo in studio
- [ ] **Phase 3 — Media + Auto Generator:** upload, FFprobe inspection,
      thumbnails, rank assignment, draft generation from template
- [ ] **Phase 4 — Timeline editor:** ruler, playhead, tracks, trim/split/move,
      snapping, undo/redo, autosave, properties inspector
- [ ] **Phase 5 — Rendering/export:** project → FFmpeg render plan, progress,
      cancel, validate output, MP4 download
- [ ] **Phase 6 — Reliability:** recovery, keyboard shortcuts, large-file tests,
      e2e Playwright smoke tests
- [ ] **Phase 7 — Expansion:** captions, AI hooks (optional), beat/scene
      detection, keyframes, masks, cloud, accounts
